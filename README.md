# Demo project for controling network valves with QGIS

1. `git clone` this repository

2. `cd demo_qgis_server`

3. `cp .env.sample .env` and edit its content according to your local environment

4. `cp conf/pg_service.conf.sample conf/pg_service.conf` and edit its content according to your local environment

5. `chmod +x restart.sh`

6. `./restart.sh` and keep an eye on the server logs during testing...
